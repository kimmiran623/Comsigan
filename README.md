# 컴시간 전 학급 시간표 대시보드

## 학교 변경
GitHub 저장소 최상위의 `school.txt` 파일을 열어 **첫 줄의 학교명**을 정확히 수정하고 Commit changes를 누릅니다.

예시:
```
서귀포대신중학교
```

Vercel에 연결된 GitHub 기본 브랜치에 커밋하면 자동 재배포됩니다. 같은 이름의 학교가 여러 곳 검색되면 안전하게 오류를 표시합니다.

## 화면
월~금 요일을 선택하면 1~3학년의 전체 학급이 한 표에 표시됩니다. 학급 개수는 컴시간 응답에서 자동 산출합니다. 표는 가로 스크롤이 가능합니다.

## 갱신
열린 브라우저에서 60분마다 API를 새로 호출합니다. 수동 새로고침도 가능합니다. Vercel 서버리스 실행 환경은 인스턴스마다 캐시가 독립적이므로 서버 전체에서 정확히 매시간 자동 수집하는 기능은 아닙니다.

## 배포
`package.json`, `server.js`, `school.txt`, `public/index.html`을 GitHub 저장소의 루트에 업로드합니다. Vercel에서 Framework Preset: Express, Root Directory: ./ 로 배포합니다.

## 주의
컴시간 비공식 파서에 의존하므로 원본 사이트의 구조가 바뀌면 조회가 실패할 수 있습니다. 컴시간 이용약관 및 데이터 공개 범위도 확인하세요. 이 환경에서는 실시간 컴시간 응답과 Vercel 배포 성공 여부를 검증하지 않았습니다.

## 한국 날짜 자동 적용
- 대한민국 표준시(Asia/Seoul)를 기준으로 오늘 날짜와 요일을 표시합니다.
- 평일은 오늘 요일을 기본 선택하며, 토·일요일은 다음 월요일을 기본 선택합니다.
- 날짜가 바뀌면 선택 요일과 날짜를 자동 갱신하고 최신 시간표를 다시 조회합니다.
- 요일을 수동 선택하면 해당 요일의 날짜가 함께 표시됩니다.
- 컴시간 데이터가 해당 날짜에 해당하는지 여부는 원본 서비스 제공 범위에 따릅니다.
