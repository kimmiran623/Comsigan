# 컴시간 전 학급 현재 시간표

- 학교 설정: `school.txt` 첫 번째 유효한 줄에 학교명 입력
- 한국 시간(KST) 기준 오늘 요일 자동 표시, 주말에는 다음 월요일
- 1~3학년 모든 반을 한 표에 표시
- 과목별 일관된 파스텔 색상, 큰 글씨, 변경 수업 테두리
- 60분마다 재조회(웹페이지가 열려 있는 동안), 수동 새로고침

## GitHub 업데이트
저장소 최상위에 `server.js`, `package.json`, `school.txt`, `public/index.html`을 배치하세요. ZIP의 상위 폴더를 통째로 올리지 마세요.

## 주의
변경 강조는 파서의 `isModify` 또는 `changed` 필드가 존재할 때만 동작합니다. 필드가 없다면 변경된 수업도 강조되지 않습니다. Vercel 서버리스 캐시는 요청마다 유지되지 않을 수 있습니다. 실제 컴시간 데이터 조회 및 배포는 별도 검증이 필요합니다.
