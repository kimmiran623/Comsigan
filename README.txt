서귀포대신중학교 2학년 1반 컴시간 시간표 웹앱

준비: Windows에 Node.js LTS 설치 (https://nodejs.org/)
1. 압축을 풉니다.
2. 폴더에서 터미널(PowerShell 또는 cmd)을 엽니다.
3. npm install
4. npm start
5. 브라우저에서 http://localhost:3000 접속

참고: 비공식 comcigan-parser를 사용합니다. 원본 사이트 구조가 바뀌면 동작하지 않을 수 있습니다. 인터넷 연결이 필요합니다. 서버를 실행한 컴퓨터에서만 접속 가능합니다.
이번 주/다음 주 이동은 포함하지 않았습니다. 파서가 반환하는 최신 주간 데이터만 표시합니다.
